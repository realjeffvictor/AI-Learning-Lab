# Product Specification

## Identity
Name: AI Learning Lab. Tagline: From Python Foundations to Intelligent Automation.
Audience: beginners, aspiring developers and AI engineers, developers moving into AI, automation builders.
Model: personal learning first; multi-user (student, instructor, admin) by architecture from day one.

## Mission
Graduates can design, build, verify, deploy and maintain AI-powered software, and can explain the systems they build.

## Five principles (drive curriculum, tutor, assessments, projects)
UNDERSTAND, DIRECT, BUILD, VERIFY, OWN.

## Competence categories
- A Deep understanding: logic, types, data structures, functions, OOP, algorithms, state, SQL, client-server, HTTP/APIs, auth/security, architecture, debugging/testing, Git.
- B AI-assisted implementation: boilerplate, repetition, explanations, integrations, DB code, docs, tests, refactoring, components, debugging help.
- C Engineering judgment: tech selection, trade-offs, security review, reviewing AI code, root-cause diagnosis, complexity, performance.
Assessment weights understanding, reasoning, quality and maintainability, never speed of producing code alone.

## Curriculum
L1 Python Fundamentals (project: expense tracker)
L2 Data Manipulation (project: financial data analysis)
L3 APIs and External Systems (project: data collection app)
L4 AI Models (project: document assistant with RAG)
L5 AI-Powered Automation (project: business automation system)
Horizontal track: AI-Assisted Software Engineering (12 modules), embedded in assignments across all levels.
Honesty rule: only authored lessons are shown as available. Unauthored lessons are labelled "Planned".

## Core loop
Learn → Practice (exercise, puzzle or game) → Submit → immediate score → per-concept weakness analysis →
recommended platform lessons plus curated external resources (YouTube, open-source) → retry.

## AI assistance modes
1 Independent (AI off). 2 Hint (no answers). 3 Pair programming. 4 Generate and Explain. 5 Code Review (identify, do not rewrite).
Tutor context: course, module, lesson, exercise, past mistakes, mode, competency level.

## Features
Auth and users; dashboard; curriculum, courses, modules, lessons; lesson workspace; Python playground; exercises;
quizzes; puzzles and games; AI tutor and five assistants (code, debug, architecture, testing, docs) plus code reviewer;
projects and submissions; progress and competency tracking; achievements and certificates; instructor and admin
dashboards; notifications and recommendations.
Rule: no decorative controls. Every control works or is clearly marked unavailable.
